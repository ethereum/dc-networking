# Consolidation: who holds the non-consolidated validators?

Moved on 2026-11-19 to the fast-finality knowledge base:
[`research/consolidation/`](https://github.com/ethereum/fast-finality/tree/main/research/consolidation).
It is a validator-set question, and this repo only uses its result.

The result used here: large holders consolidating alone bring the validator
set to about $5 \times 10^4$; the $V \to 10^4$ end of the range in
[`requirements.md`](../../design/requirements.md) needs small stakers to pool
or exit as well.
