How to read this comparison

Each line is the equal-weight mean of node profiles over common, fully captured slots after sustained transaction load is verified. The same two supernodes (1, 2) and one home node (202) are used across runs. Shading describes variation across these nodes, not network-wide uncertainty; the home view has only one node and cannot show between-node variability. The optional t interval assumes independent nodes, an assumption these shared-network captures do not establish.

Message timing uses 100 ms bins. Observed FFG records are successful validation entries; they do not include every packet received. Accepted FFG timing uses the explicit decidedMs. AC observations and acceptances deduplicate queue/replay lifecycles. Ignored aggregates have their own view. Local vote production is excluded from comparison lines. Execution payloads include every logged successful application path, including local proposals and fetched payloads. Their observed time is processing entry; their applied time uses the logger timestamp, at approximately 10 ms resolution. Repeated imports of the same payload are counted once.

Payload and Goldfish reception CDFs overlay the three runs. Each node is normalized by its total recorded observations, then nodes are weighted equally. Steps advance at the upper edges of raw 100 ms bins. Missing observations are excluded; late observations remain in the denominator. Payload reception uses processing-entry logs, including local and fetched payloads. Goldfish uses first observations with queue/replay duplicates removed and local production excluded.

RPC rates include repeated copies, control messages and encoded partial messages. They estimate protobuf RPC frames plus length prefixes. Sending means queued, not confirmed delivered; transport, encryption and retransmission overhead is outside this instrument. Raw 100 ms bins allocate bytes over actual report intervals and are shown without Gaussian smoothing. Topic layers partition the same total; other topics and unassigned control share the gray layer. Empty intervals are zeros only when a tracer record establishes coverage.

Topic and object layers use the same colors and vertical scale across runs. Raw bins are the default. In the relative-size view, the optional 150 ms Gaussian smooths the 100 ms bins while preserving their summed size; CSV includes both raw and displayed values. One size unit is one 240-byte FFG vote. Relative size weights messages by the pinned SSZ model; it is not bandwidth. Execution payloads use their actual logged SSZ size, excluding the envelope and blob sidecars. Data columns use the pinned SSZ formula and logged cell counts. Beacon blocks use conservative lower bounds from logged contents. These weights cover the three matched nodes; other detail nodes retain unmodeled events. Historical envelopes keep the original xray lower bounds. The same logged payload sizes appear in the load-evidence table. AC uses 305 bytes in the first genesis and a 205-byte structural lower bound after regenesis because its scratch-space setting was not archived. Aggregate weights change with committee size. Bundle-delivered FFG votes are logical 240-byte votes, not 240 transferred bytes per signature.

Source, exclusions and reproducibility

  • Throttled ClickHouse exports are excluded from quantitative comparisons.
  • Each node and full wall-clock slot has one selected Docker-log source. Overlapping exports are not added together.
  • Rolling deployment from 16:56–17:26 UTC, startup and empty-payload periods are excluded from comparisons. Earlier slots remain available in detail.
  • The execution-block JSON export was streamed to cross-check transaction counts and gas used. Databases, profiles and Prometheus snapshots remain packed and were not analyzed as CPU or memory evidence.
  • Regenesis is a separate chain. Node roles and committee sizes are assigned per genesis.
